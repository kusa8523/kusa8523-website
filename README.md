# KUSA8523 — Travel & Tourism Website

Premium, responsive, English-language brand website for KUSA8523.

## Run locally
Open `index.html` in a browser. No build tools are required.

## Deploy on GitHub Pages
Upload the contents of this folder (including `index.html`) to the root of your `kusa8523-website` repository. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## Project structure
- `index.html` — page markup and SEO metadata
- `css/style.css` — responsive styles
- `js/script.js` — mobile navigation, date, email draft interaction
- `assets/brand-logo.png` — official KUSA8523 branding artwork

## Important notes
- Destination photos load from Unsplash and fonts load from Google Fonts, so an internet connection is required for those resources. Images are illustrative and may change or become unavailable.
- The contact form opens the visitor's email application with a prepared draft; it does **not** send or store messages. A real business email address must be configured before launch.
- This is a brand presentation, not a travel booking engine. There are no live rates, reservations, checkout, or payment processing.
- Verify commercial image rights, accessibility, privacy disclosures, and relevant travel regulations before launching commercial services.

Brand colors: `#111111`, `#D4AF37`, `#FFFFFF`.
